# AGENTS.md

- Follow existing patterns.
- Run relevant validations after code changes.
- When running validation tests, use really small numbers only to check that the code works in a short amount of time.
- Always comment the code properly, and if the `.py` file does not have a detailed comment section, add one yourself.

## Plotting

- Use \(s_t\) for hidden-state variables.
- Use \(o_t\) for observation-space variables.
- Do not include figure titles or subplot titles unless explicitly requested.
- Put short, clear legends inside the axes.
- Never place legends outside the plot.
- Use pastel colors by default.
